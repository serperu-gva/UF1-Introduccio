# 1. Introducción

El propósito principal de la creación de programas es resolver y automatizar problemas del día a día. Esto implica que se procese información para obtener resultados a partir de datos del entorno que necesita el programa.

Cuando utilizamos un ordenador, en realidad estamos aprovechando programas que han sido creados por programadores para solucionar problemas específicos. Estos programas son como recetas detalladas que le dicen al ordenador exactamente qué hacer para transformar nuestros datos iniciales en los resultados que necesitamos.

Para crear un programa efectivo, el programador necesita:

1. Entender bien **qué información tenemos** al principio (los datos de entrada).
2. Tener claro **qué queremos obtener** al final (los resultados o datos de salida).
3. Diseñar **qué pasos** se van a seguir para convertir esta información inicial en los resultados que buscamos.

Este proceso de transformación paso a paso es lo que llamamos un algoritmo, que es como el corazón de cualquier programa.
